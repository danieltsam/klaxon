Comparison.
  • 0 Current — chips cramped, no room for descriptions.
  • A Vertical list (radios) — most info per px, scannable, settings-list feel. Adds ~30px height to sheet.
  • B iOS grouped card — native iOS pattern, full-width taps. Compact but loses per-option subtitles.
  • C Collapsed + expandable — minimal at rest, expands to 5-row list. Smallest footprint by default.
  • G Recurrence row in Pick Date — consolidates date + recurrence into one sheet. Schedule sheet becomes just a time picker. Bigger single-modal change.
  • H Recurrence as 5th Tab — fits existing tab pattern (Ribbon/Matrix/Tumbler/Type). User has to tap tab to find recurrence — extra step.

About Custom. In all 6 mockups, tapping "Custom" would expand into the existing weekday selector (M T W T F S S circles). The follow-up UI doesn't change — only the entry-point does.
