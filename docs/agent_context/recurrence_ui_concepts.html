Summary of options.
  • A Vertical list (radios) — most info-dense, scannable, familiar settings pattern. Best for power users.
  • B iOS grouped card (checkmarks) — native iOS feel, full-width taps, single card visual. Best for iOS aesthetic.
  • C Collapsed + expandable — minimal footprint when at rest, expands on tap. Best when screen real estate is tight.
  • D Wheel picker — consistent with the time picker drum tumbler. Tactile, mechanical, fun.
  • E Segmented toggle grid — compact 2/3 layout, familiar toggle UX. Best when space is limited.
  • F Bento tile grid — icons + descriptions, visual and tappable. Best for discoverability.

About Custom. Custom is the only option that requires a follow-up step (pick specific days). In all 6 concepts above, tapping "Custom" would expand into the weekday selector (M T W T F S S circles) — same behavior as today. After selecting the mockups, we can refine how that follow-up UI presents itself.
