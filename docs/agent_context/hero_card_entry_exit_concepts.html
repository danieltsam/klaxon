How to read these. All five concepts share the same in-card content. The only thing changing is the motion that happens when the hero first appears and when it disappears. Concepts loop their full entry → dwell → exit cycle every 7 seconds so you can compare them back-to-back without manual interaction.

Current implementation vs concepts:
  • Reference (today): AnimatedSize (350ms cubic) + AnimatedSwitcher (280ms fade + size). Utilitarian.
  • α Slide-up Spring: CurvedMotion + Tween (offset+scale) ~900ms entry / 550ms exit. Closest to current but with energy.
  • β Morph from List: Custom Hero widget or shared-axis SharedAxisTransition. Highest implementation effort, strongest visual payoff.
  • γ Glassmorphic Bloom: BackdropFilter + AnimationController for border-radius/scale. ~850ms entry. Pair with subtle haptic on bloom apex.
  • δ Scale + Stagger: AnimatedSwitcher per row with stagger intervals (TweenAnimationBuilder). Easy to compose with existing AnimatedSize.
  • ε Liquid Blob: Tween<BorderRadius> + Transform.scale. ~1s morph. Most distinctive but most "different" from current aesthetic.

To explore live, open this file in any browser. Animations loop on a 7-second cycle — let them play 2–3 times each to see the full entry → dwell → exit motion.
