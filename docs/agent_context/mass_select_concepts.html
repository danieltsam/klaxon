Comparison.
  • A Long-press multi-select — most discoverable, fastest for batch delete. Best for your audience (technical, wants efficiency). Standard iOS/Android pattern.
  • B Swipe + Edit toolbar — Material-Design-native (Dismissible pattern). Familiar Android users. Two modes (single vs bulk) but requires switching between them.
  • C Long-press action sheet + Select all — more menu options per row (Duplicate, Pause). Bulk delete only via Select all. No multi-select mode. Cleaner for single-row actions.
