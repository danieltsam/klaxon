Animation & Haptics

Ideas to layer in as polish passes. Not all need to ship — pick what feels right on device.

Hero Card Animations

⏳ Live Countdown Ticker Easy

When the hero card is visible, show a smoothly incrementing seconds-remaining counter (AnimatedFlipCounter or custom digit roll). The digits tick down every second, giving the card a live, purposeful feel — like a race timer.

🌊 Wave Pulse on Arm Easy

When an alarm arms, a soft indigo ripple radiates outward from the alarm card for ~600ms (AnimationController + ScaleTransition on a decoration). Confirms the action with a satisfying pulse.

🔢 Digit Morph (Hero Time) Medium

Instead of the time snapping when the user edits, each digit individually rolls up/down (AnimatedSwitcher with a vertical slide per digit position). Looks like a mechanical flip-clock. Tabular figures keep columns stable.

✨ List Item Entrance Easy

When a new alarm is added, it slides in from the bottom with a fade (SizeTransition + FadeTransition inside an AnimatedList). Currently alarms snap in. Animated insertion is noticeably more polished.

🌙 Dark Pulse on Disable Medium

When toggling an alarm off, the card dims with a subtle dark vignette fade over ~250ms before collapsing. Reinforces the "this alarm is now inactive" state change with visual weight.

Haptics Ideation

Moment Pattern description Effort
Alarm armed Double thud — a strong impact followed 80ms later by a lighter one. Feels like a door latching shut. Confirmed, locked in. Easy
Alarm disarmed Single soft buzz — lighter than a click. Intentionally less satisfying than arming. Reinforces asymmetry of intent. Easy
Drum scroll tick Current: selectionClick per step. Upgrade: vary intensity — heavier tick every 5-unit boundary (e.g. :00, :05). Orientation feedback. Medium
Preset chip tap Light impact + soft follow. Two-part: the tap registers, then the drum animates to position with a final gentle thud on arrival. Medium
Confirm time Medium impact + brief vibrate pattern (~100ms). Distinct from all other actions — punctuates the gesture of "setting" the alarm. Easy
Swipe-to-delete Soft elastic spring as the alarm slides off — light buzz at rest, heavier pop at delete threshold, then silence. Feels physical. Medium
Countdown acceleration In the final 5 minutes before alarm: selectionClick ticks in the hero card accelerate — 60s→30s→15s→5s intervals. Builds tension passively. Hard
Sheet open / close Very soft, near-imperceptible buzz as modal slides up. Confirms touch registration before animation completes. Easy
Flutter API — HapticFeedback.lightImpact(), .mediumImpact(), .heavyImpact(), .vibrate(). For precise patterns on Android, use the vibration package (Vibration.vibrate(pattern: [0, 80, 80, 40])). iOS uses CoreHaptics via flutter_haptic or haptic_feedback.
